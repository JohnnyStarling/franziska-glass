# Стадия проекта

Подготовлено 5 ноября 2026 года по сохранённым результатам 26–30 октября. Новая физическая проверка устройств при подготовке страницы не проводилась.

## Что различаем

«Реализовано», «установлено» и «проверено в реальном сценарии» — разные результаты. Ниже указан фактический уровень подтверждения.

| Возможность | Что подтверждено | Что ещё не установлено |
| --- | --- | --- |
| Приложения Glass / Pixel | Последняя документированная пара ассистента — Glass56 / Pixel50; установочные файлы сверены считыванием с устройств | Это не новая сегодняшняя инспекция и не приёмка всех функций |
| Голос / основной агент | Голосовая интеграция и реальные обращения к основному агенту в записанных сеансах | Длительный непрерывный разговор, полное озвучивание длинных ответов, отсутствие заиканий |
| Чат и статусы | Интерфейсы установлены; экран состояния наблюдался | Читаемость через призму, история и жесты в полноценном использовании |
| Фото / галерея | Установлены компоненты; нативная галерея Pixel наблюдалась | Полный текущий сценарий камера → оригинал → просмотр / выбор / удаление |
| Мобильная связь | Защищённый сокет Glass–Pixel и авторизация OpenClaw при мобильном upstream/VPN | Голосовой разговор в этих условиях, прогулка без USB, работа после перезагрузки |
| Восстановление связи | Реальный цикл выключения/включения точки доступа с возвратом связи; наблюдалось около 28 секунд | Гарантированное время восстановления во всех сетях и после reboot |
| Расчёт маршрутов | Локальные маршруты для пешехода, велосипеда и автомобиля в установленном OsmAnd | Полноценные поездки с полностью отключённым интернетом |
| Подсказки на Glass | Меняющиеся карта, манёвры и расстояния по Bluetooth при заблокированном Pixel в нативной симуляции | Реальный GPS-маршрут, полевой rerouting, оптическая приёмка |
| Автономность | Архитектура навигации не зависит от Mac/OpenClaw | Срок работы от батареи и допустимый нагрев; AI без доступного Mac не заявляется |

## Условия использования прототипа

- Для AI требуется доступный Mac с OpenClaw и интернет-маршрут от Pixel.
- Для переносной связи ассистента используется Wi-Fi-точка Pixel; включение системной точки доступа остаётся явным действием пользователя.
- Навигация — отдельные приложения OsmAnd/OsmGlass с Bluetooth-связью.
- Проверка защищённой авторизации сама по себе не означает, что состоялся разговор.
- Встроенная симуляция навигации не является доказательством реального GPS.
- Пересылка телефонных уведомлений в очки не включена.
